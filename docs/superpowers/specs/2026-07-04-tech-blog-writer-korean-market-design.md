# tech-blog-writer 한국 시장 개선 — 설계

- 작성일: 2026-07-04
- 대상: `.claude/skills/tech-blog-writer/` (스킬 파일 편집 전용)
- 비대상: 라이브 블로그 코드(`apps/web`)는 건드리지 않음

## 배경 / 문제

`tech-blog-writer` 스킬은 이미 토스/LINE/쏘카/44bits 실제 관행 기반으로 잘 만들어져 있고,
톤 가이드·환각 검증까지 갖춰져 있다. 다만 "한국 시장 적합성" 관점에서 두 가지 실질 갭이 있다.

1. **윤문 파이프라인 미연동**: 스킬이 "AI 슬롭 회피"를 *원칙*으로만 언급하고,
   실제로 이미 설치된 `ai-slop-reviewer`·`humanize-korean` 스킬을 **호출하는 단계가 없다.**
2. **한국 검색 현실 미반영**: 현재 SEO 지침이 구글/AI검색 프레이밍뿐이고,
   네이버(점유율 ~60%) 대응·발행 후 배포 전략이 없다.

기술 SEO 토대(`robots.ts`·`sitemap.ts`·`feed.xml`·`opengraph-image.tsx`·`generateMetadata`·JSON-LD BlogPosting)는
블로그에 **이미 구현되어 있음**을 확인했다. 따라서 개선은 코드가 아니라 **글쓰기 스킬 자체**에 집중한다.

## 목표

- 초안 작성 후 한국어 AI 티를 정밀 제거하는 **윤문 게이트**를 워크플로에 명시적으로 넣는다.
- 네이버 현실·구글·GEO/AEO·발행 후 배포를 담은 **한국 검색 레퍼런스**를 추가한다.
- 기존 스킬의 목소리(진정성 회고형)와 검증된 수치를 **훼손하지 않는다.**

## 비목표 (YAGNI)

- 네이버 SEO 독립 스킬 제작(과함) — 레퍼런스 파일로 충분.
- 네이버 Search Advisor 소유확인 메타태그를 `layout.tsx`에 삽입 — 별도 후속(네이버 계정 필요).
- 톤 가이드 전면 재작성 — 이미 견고. 최소 보정만.

## 변경 상세

### 변경 1 — 윤문 게이트 단계 신설 (`SKILL.md`)

워크플로 순서를 다음과 같이 바꾼다:

```
... → 5. 경량 웹 검증 → [신규] 6. 윤문 패스 → 7. 대화 내 검토(발행 게이트) → 8. 발행 → 9. 발행 후 배포
```

윤문 패스 규칙:

- 순서: `ai-slop-reviewer`(1차 일반 기계패턴 제거) → `humanize-korean`(2차 한국어 정밀 윤문).
- 성격은 **강제 재작성이 아니라 리뷰**: 감지된 AI 티만 표시하고 저자 확인 후 반영.
  Claude가 이미 톤을 맞춰 썼다면 대부분 통과한다.
- 안전장치를 신뢰: 두 스킬은 고유명사·수치·날짜·인용을 100% 보존하고,
  변경률 30% 초과 시 경고·50% 초과 시 중단 → 검증된 버전 수치·진정성 목소리 보호.
- 코드 블록·수치·인용은 윤문 대상에서 제외됨을 명시.

### 변경 2 — `references/korean-seo.md` 신설

섹션 구성:

- **네이버 현실**: 자체 Next.js 블로그는 네이버 외부 사이트 노출에 제약이 큼.
  C-Rank/D.I.A. 개념(신선도·체류·클릭·문서 자체 품질 중시), 키워드 스터핑 역효과.
- **실행 지침(글쓰기 관점)**: 제목 ~40자(SERP 잘림 회피), 첫 문단에 핵심 키워드 자연스럽게,
  네이버 웹마스터도구(Search Advisor) 등록·사이트맵 제출 안내(실행은 사용자 몫).
- **구글**: 이미 JSON-LD·OG·sitemap 구현됨 → 유지, 글 관점 강화 포인트만(제목·description·H 태그 구조).
- **GEO/AEO**: 통계·조사 방법·데이터 출처·요약 문단으로 AI 검색(ChatGPT/Perplexity) 인용 유도, E-E-A-T.
  → `korean-writing.md`에 흩어진 GEO/AEO 조각을 이 파일로 이관·통합.
- **발행 후 배포 체크리스트**: GeekNews(긱뉴스) 제출, 커뮤니티(커리어리/OKKY 등) 공유,
  자체 채널(RSS/피드) 확인.

출처는 방향성 참고용이며, 구체 수치·URL은 발행 전 경량 웹 검증 단계로 확인한다(기존 원칙 일관).

### 변경 3 — `SKILL.md` 참조 로드 & 단계 보강

- **레퍼런스 로드**: 검토/발행 단계(제목·메타데이터 확정 시) `korean-seo.md`를 로드하도록 명시.
- **발행 후 배포 단계 추가**: 워크플로 말미에 "9. 발행 후 배포"를 추가하고 korean-seo.md 체크리스트를 가리킴.

### 변경 4 — `korean-writing.md` 미세 보정

- 윤문 게이트와 상호 링크(윤문은 korean-seo가 아니라 이 톤 가이드를 기준으로 판단).
- SEO/GEO 조각을 `korean-seo.md`로 이관하며 중복 제거. 그 외 톤 규칙은 유지.

## 검증 방법

- 스킬 문서 편집이므로 자동 테스트 대상은 없음.
- 수용 기준: 스킬을 새로 트리거했을 때 (1) 초안 후 윤문 패스가 단계로 등장, (2) 검토 단계에서
  korean-seo.md가 로드되어 제목 길이·네이버/배포 지침이 반영, (3) 발행 후 배포 체크리스트 제시.
- 실제 샘플 글 한 편으로 워크플로를 드라이런하여 단계 흐름을 눈으로 확인.
